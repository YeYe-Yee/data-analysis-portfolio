# Cookie Cats 关卡位置 A/B 实验分析

## 1. 业务问题

游戏 Cookie Cats 把新手首个付费关卡从第 30 关移到第 40 关，是否会提升玩家留存？是否应该上线？

## 2. 数据

- 来源：Kaggle — Mobile Games: A/B Testing
- 规模：90,189 名新安装玩家，随机分为 gate_30（44,700）与 gate_40（45,489）
- 字段：userid、version、sum_gamerounds（14 天轮次）、retention_1、retention_7
- 局限：无关卡进度数据、无付费数据、仅 14 天窗口、无设备/地区等协变量

## 3. 方法

1. **实验设计复盘**：重建实验方案，计算 MDE 与样本量（7 日留存 MDE = 0.73pp，相对 3.9%）
2. **数据可信性**：SRM 卡方检验（χ²=6.902，p=0.0086，未检测到 SRM）+ 伪 AA 测试
3. **主分析**：两样本比例 z 检验、卡方交叉验证、Wald 与 Bootstrap 置信区间、Cohen's h
4. **轮次分析**：因分布严重右偏，用 Mann-Whitney U 替代 t 检验，并以 99% 截尾 t 检验作对照
5. **稳健性检验**：6 个维度、10 项检验 + 4 个安装批次分层

## 4. 核心结论

- **7 日留存显著下降**：19.02% → 18.20%（-0.82pp，相对 -4.31%，p=0.0016，95%CI [+0.31, +1.33]pp）
- **1 日留存无显著差异**（p=0.0744），但方向与主指标一致
- **游戏轮次无显著差异**（Mann-Whitney p=0.050，效应量 r=0.0065 可忽略）
- 结论在 4 个安装批次分层中方向完全一致，**不是抽样波动**

## 5. 建议

1. 维持 30 关门槛，不推进全量上线
2. 优先排查第 31–40 关的体验断点（难度曲线、奖励密度、重复关卡）——玩家在未遇到付费墙的区间就已流失
3. 若再次验证，需补充关卡进度埋点、付费数据、30/60 日窗口，样本量提至每组 17.5 万

## 6. 局限与反思

- 无法区分"31–40 关内容差"与"付费墙时点后移"两种机制（缺关卡进度数据）
- 无付费数据，无法评估留存与变现的权衡
- 仅 14 天窗口，无法评估长期留存与 LTV
- 方法论反思：本项目最难的是**选对检验方法**（右偏数据不能用 t 检验）、**正确解读边缘 p 值**、以及**把统计结论翻译成业务语言**
