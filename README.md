# 数据分析作品集

应用统计硕士在读，方向：互联网数据分析 / 用户增长。

## 项目

### 1. Cookie Cats 关卡位置 A/B 实验
- 用 9 万玩家真实随机分流数据，评估"把关卡从 30 关移到 40 关"对留存的影响
- 方法：MDE 与样本量测算、SRM 校验、比例检验、Bootstrap 置信区间、分层稳健性检验
- **结论：40 关方案使 7 日留存显著下降 0.82pp（相对 -4.31%，p=0.0016），
  且在 4 个安装批次中一致成立；按日增 10 万测算年损失约 30 万留存用户，建议维持 30 关。**
- 工程：[完整报告](01-cookie-cats/report/analysis_report.md) 

### 2. Olist 电商履约体验分析
- 基于 10 万订单、9 张关联表的巴西电商数据，回答「物流延迟伤害用户到什么程度、通过什么路径」
- 方法：多表建模与宽表设计（`order_level` / `customer_level`）、延迟分箱与月度/州级三重稳健性检验、
  **葡语评论文本分类（40,774 条正文）**、cohort 复购分析（先算 MDE 再决定分析粒度）、两比例 z 检验
- **结论：延迟的伤害是非线性的——迟到 1 天几乎无感，迟到满 3 天差评率从 34.3% 跃至 50.4%，
  7 天以上顶格在 70%~85%；该断点在全国 27 州、20 个月上均成立，与当地物流水平无关（r=+0.09）。
  文本侧证实差评 40.77% 明确抱怨物流（提商品质量的 28.07%），且延迟越久越「纯物流」——
  迟到 7 天以上抱怨物流升至 70.91%、提质量塌至 1.93%。首单延迟使复购率从 2.85% 降至 1.97%
  （z=3.34），但迟到单仅占 8%，显著 ≠ 重要。**
- 工程：[完整报告](02-olist/report/analysis_report.md) ｜ 19 项数据质量审计 ｜ 85+ 条指标口径登记表 ｜
  SQL 5 份 + Python 3 个脚本，可复现全部图表与数字
