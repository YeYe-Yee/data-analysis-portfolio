## 8. 口径冲突备忘（易错点）

| 场景 | 错误用法 | 正确用法 |
|---|---|---|
| 延误率 | 混用 8.11% / 8.06% | 报延误率用 `is_late` 8.11%；分箱归因用 `delay_days` |
| 复购率 | 引用 3.00% 或 2.91% | 统一 2.05%（严格口径，分母 96,096） |
| 差评率 | 引用旧值 12.77% | 12.81%（分母 95,823，非 96,470） |
| 延迟分箱 | `delay_days <= 15` | `< 16`，否则 (15,16) 的 150 单归错箱 |
| 复购判定 | `DATEDIFF >= 0` | `>= 1`，剔除同日拆单 |
| 标准误/方差 | `1/n` | `1e0/n` 或 `CAST AS DOUBLE` |
| 文本差评率 | 用 40,774 当分母去算整体差评率 | 文本只做组间对比；整体差评率分母是 95,823 |
| 判送达 | 依据评论里的“没收到” | 依据 `order_delivered_customer_date`；11.27% 评价写在送达前 |
