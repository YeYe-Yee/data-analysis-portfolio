# Olist 电商履约体验分析

> 用 10 万订单回答一个问题：**物流延迟到底怎样伤害用户？伤害到什么程度会不可逆？**

📄 **完整分析报告：[`report/analysis_report.md`](report/analysis_report.md)**（含图表、稳健性检验、建议与局限）

## 1. 业务问题

巴西电商平台 Olist 的差评与低复购，是否能归因于物流延迟？如果是，**延迟多少天是临界点**？平台应该优先改善哪类订单的履约？

拆成三个可检验的子问题：

1. **基线**：平台的履约与满意度处于什么水平？（第 1 段）
2. **归因**：延迟天数与差评率之间是非线性还是线性？拐点在哪？（第 2 段）
3. **文本验证**：给差评的人，真的在骂物流吗？（第 3 段）
4. **后果**：延迟与差评是否影响复购？影响多大？（第 4 段）

## 2. 数据

- **来源**：Kaggle - Brazilian E-Commerce Public Dataset by Olist
- **规模**：99,441 笔订单、9 张关联表、112,650 个商品行、96,096 位客户
- **时间范围**：2016-09-04 ~ 2018-10-17（有效分析窗口 2017-01 ~ 2018-08）
- **环境**：MySQL 8.x，`olist` schema，全部指标由 SQL 计算，无手工加工

数据质量问题 **19 项**（详见 [数据质量审计](report/data_quality_audit.md)），其中影响结论的五个已修复或已作口径约定：

| 问题 | 影响 | 处置 |
|---|---|---|
| `review_id` 不唯一（814 行） | JOIN 后订单膨胀 | 按订单取最新一条评价 |
| geolocation 42 行境外坐标 | 邮编坐标污染 | bbox 过滤后按邮编聚合 |
| **同日多单被当复购（853 对）** | 复购率虚高 30% | 复购定义加 `gap ≥ 1 天` |
| **延迟分箱边界错位（150 单）** | 15/16 天两箱样本错配 | 改用闭开区间 `< 16` |
| **文本样本自选偏差（41.32% 有正文）** | 文本差评率是全样本 1.8 倍 | 只做组间对比，不做总体推断 |

## 3. 方法

**数据建模**：[ER 图与表关系](report/er_diagram.md) ｜ [数据字典](report/data_dictionary.md) ｜ [指标口径登记表](report/metrics_registry.md)

**分析链路**（五段式，全部可复现，见 `sql/` 与 `scripts/`）：

| 阶段 | 产出 | 关键设计 |
|---|---|---|
| 1. 宽表与基线 | `order_level`（99,441 × 20） | 先 `GROUP BY order_id` 再 JOIN，规避 1.142×/1.006× 双膨胀；多评价取最新一条 |
| 2. 归因 | 延迟逐日曲线、月度/州维度稳健性 | 用 `delay_days` 而非 `is_late` 分箱；以 `SUM(条件)` 做样本量锚点校验 |
| 3. 文本验证 | 40,774 条葡语正文的主题分类 | 先量自选偏差（1★ 开口率 76.62% vs 4★ 31.25%）再做组间对比；只判断"是否提及"，不做情感打分 |
| 4. 复购 | `customer_level`（96,096 × 15） | cohort 截断消除右删失；先算 MDE 再决定能切几层 |
| 5. 建议 | 见下 | 所有结论标注口径与置信区间 |

**为什么先算 MDE**：复购率仅 2.05%，若不先估计「最小可检测差异」，任何分层都会得到一堆不显著的格子并被误读为「无影响」。本研究两组对比的 MDE = **0.73pp（相对 26%）**，据此放弃了州 × 体验、品类 × 体验的交叉分析。

## 4. 核心结论

**① 延迟的伤害是非线性的，临界点在「迟到满 3 天」。**

下表为全样本（有评价的送达订单，剔除提前 15 天以上的极端早到）按迟到天数分箱；完整 15 档见报告 5.1 节。

| 迟到程度 | 订单数 | 差评率 | 一星率 |
|---|---:|---:|---:|
| 准时及提前 3 天内 | 4,796 | 11.12% | 7.88% |
| 迟到不足 1 天 | 1,239 | 12.88% | 8.80% |
| 迟到满 2 天 | 545 | 34.33% | 27.43% |
| **迟到满 3 天** | **500** | **50.40%** | **42.54%** |
| 迟到满 6 天 | 419 | 76.66% | 68.55% |
| 迟到 30 天以上 | 359 | 68.42% | 64.04% |

迟到 1 天几乎无感（+1.8pp）；第 3 天一天之内跨过「一半用户差评」的线；7 天以上进入平台期（70%~85%），再加天数边际伤害递减。

**② 8.1% 的迟到订单贡献了 33.7% 的差评。** 迟到订单差评率 54.43%，非迟到 9.22%，**相对风险 5.9 倍**。

**③ 差评文本证实：用户在骂的是物流，不是商品。**

| 差评文本归类（互斥，n=10,839） | 占比 |
|---|---:|
| 仅物流（抱怨）| **26.66%** |
| 物流 + 服务（多为「没收到 + 客服不理」）| 9.18% |
| 仅商品质量 | 16.43% |
| 未识别（纯情绪表达等）| 24.85% |

（其余四类合计 22.89%：仅服务/退款 11.25%、质量 + 服务 6.71%、物流 + 质量 2.62%、三者都提 2.31%，完整表见报告 6.2 节。）

含「抱怨物流」**40.77%**、含商品质量 **28.07%**——**物流是差评最大的单一来源，约为质量问题的 1.5 倍**。且延迟越久越「纯物流」：抱怨物流的比例从准时订单的 **25.24%** 升到迟到 7 天以上的 **70.91%**，同期提商品质量的比例从 **43.85% 塌到 1.93%**——若延迟与差评只是伪相关（真因是商品差），这一项不该下降 23 倍。

**④ 这个「3 天断点」与物流基础设施无关。** 20 个月中 `bad_3_6` 稳定在 46.0%~72.7%（均值 58.5%）；12 个样本充足州的 `bad_3_6` 在 54.4%~83.3%（均值 62.2%），覆盖 92.6% 样本。各州平均送达时长相差 **2.8 倍**（SP 8.7 天 vs AL 24.5 天），但「迟到 3~6 天」的差评率只差 1.5 倍——**修好物流不会让用户对延期更宽容**。

**⑤ 「压线准时」已经在扣分。** 准时及提前 3 天内到货差评率 11.12%，提前 8~15 天只有 8.71%，差 2.4pp。预计送达日的缓冲本身就是体验。

**⑥ 首单延迟显著降低复购，且不能被满意度解释。**

| 首单延迟 | 人数 | 复购率 |
|---|---:|---:|
| 准时 | 51,196 | 2.85% |
| 迟到 | 4,263 | 1.97% |

相对降幅 **30.8%**（z = 3.34，p ≈ 0.0008，95% CI [0.36, 1.39]pp）。分地区方向一致：SP −0.84pp、非 SP −0.80pp。

**「迟到 + 好评」2.12% ≈ 「准时 + 差评」2.29%** —— 延迟有独立于满意度的效应，靠道歉和补偿挽回不了复购。

**⑦ 但业务杠杆有限。** 迟到订单仅占 8.1%，即使完全消除延误，cohort 内整体复购率也只从 **2.78%** 升到 **2.85%**（+0.07pp）。**统计显著 ≠ 业务重要。**

## 5. 建议

**① 把补偿与主动沟通的触发线定在「迟到满 3 天」，不是「超过承诺日」。**
1 天的延迟用户几乎无感（12.88% vs 11.12%），在 1~2 天介入是资源浪费；第 3 天差评率跳到 50.40%，此时主动触达的边际收益最高。文本侧同向：迟到 3~6 天的差评里 68.23% 在抱怨物流、53.75% 直接说「还没收到」——**这一档要给的是轨迹信息，不是话术**。

**② 资源投放分三类，不能一刀切。**

| 类型 | 地区 | 特征 | 动作 |
|---|---|---|---|
| 「量」的问题 | BA、ES、AL | 延误率 12%~24%，平均送达 16~25 天 | 提时效：换承运商、前置仓 |
| 「质」的问题 | RJ | 延误率 13.4%（第 3），但 `bad_3_6` 69.6%、`bad_ge7` 83.6% 双项全国最高 | 提容忍度：主动告知 + 延误即补偿 |
| 「跳档」地区 | CE、SE、PE、MA、PA | `n_ge7 / n_3_6` 达 2.4~4.4，延误直接跳过 3~6 天档 | 提前预判 + 改派兜底（3 天补救无效） |

**③ 承诺期加 2~3 天缓冲，比压缩实际时效更划算。** 提前 8~15 天到货的差评率比压线准时低 2.4pp，而承诺期调整零边际成本。注意这不等于「故意报慢」——需与实际时效改善配套。

**④ 复购不要指望物流。** 延迟对复购的统计效应显著，但杠杆不足 0.1pp；提升复购应优先非物流手段（会员、复购券、品类交叉）。

## 6. 局限与反思

**① 观测性研究，非因果推断。** 未做随机化或匹配，未控制卖家、品类、客单价。「延迟 → 差评」与「延迟 → 复购」均属相关关系；RJ 的异常（伤害最高但延误率仅第 3）说明存在未观测的地区性因素。

**② 右删失处理带来样本损失。** 数据截止 2018-10-17，为保证观察窗一致，cohort 截断到首单 ≤ 2018-02-28，样本 55,459（57.7%），并刻意排除了 2018-03 爆仓月，避免其系统性拉偏体验变量。

**③ 小分母限制了可检验的假设。** 复购率 2.05%，MDE 0.73pp（相对 26%）。**「未检出显著」应理解为「效应小于可检测下限」，而非「无影响」**——这是本报告放弃大量交叉分析的原因。

**④ 评价存在自选偏差，差评率被低估。** 评价覆盖率随延迟单调下降：准时组 99.5% → 迟到 16~30 天 96.9% → 30 天以上 95.3%。越不满意的用户越可能直接沉默，因此 78%~82% 的差评率是**下限**。

**⑤ 迟到 30 天以上（359 单）的差评率回落到 68.42%，无法归因。** 两个可检验机制均被否定：承诺期长度两组几乎相同（25.9 vs 25.1 天，排除「乱承诺」）；金额对账差额接近 0（+0.38 vs −0.02，排除「退款挽回」）。该群体呈双峰（64% 一星 + 13% 五星），近半产生于 2017-11、2018-02、2018-03 三个履约高压窗口，推测是「长期等待后放弃预期」的心理重置与自我选择，**但本数据无法验证，故不作因果解读**。

**⑥ 文本分析受限于语料与方法。** 只有 41.32% 的评价带正文，且 1★ 开口率（76.62%）是 4★ 的两倍多，文本样本的差评率是全样本的 1.8 倍，**不能用于推断整体差评的原因构成**；葡语无标注语料，只能用关键词法做「提及/抱怨」的判断，未识别 24.85%，各主题绝对份额被低估；11.27% 的评价写在送达之前（「说没收到」中占 40.42%），文本里的「未收到」是等待焦虑而非永久丢件。

**⑦ 四条可复用的方法论教训。**

1. **口径先行，比率必须写明分母。** 本项目 4 次「预期对不上」全部源于分母口径错误（复购率 3.00% vs 2.91% vs 2.05%、差评率 12.77% vs 12.81%、文本 40,774 vs 98,672）。
2. **定义决定结论。** 剔除同日拆单后，延迟对复购的效应从 −0.80pp 扩大到 −0.88pp（z 从 2.57 升至 3.34）——错误的定义会**稀释**真实效应，而不是随机加噪。
3. **分箱必须用无歧义条件 + 独立锚点校验。** `delay_days <= 15` 导致 (15,16) 的 150 单归错箱；MySQL 的 `1/n` 只保留 4 位小数，使标准误被低估、z 值虚高（3.78 vs 3.34）。
4. **文本分析的第一步是量「谁开口」。** 覆盖率看着有 41%，但开口率随评分变化近 2 倍——不先量化这个偏差，任何「差评里 70% 是物流」都会被误读成「整体差评 70% 是物流」。
